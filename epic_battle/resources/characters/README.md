# Placeholder Images

This folder contains placeholder files that show the expected naming convention and structure for the actual images.

## To replace placeholders:
1. Create your actual images following the naming convention
2. Replace the .placeholder files with your .png or .jpg images
3. Keep the same names but change the extension

## Character Images Needed:
- Characters should be PNG format with transparent backgrounds
- Recommended size: 200x300px
- Show characters clearly holding their weapons

## Background Images Needed:
- Can be JPG or PNG format
- Recommended size: 800x400px
- Should represent the battle locations clearly

## Defeated Character Images:
- PNG format with transparent backgrounds
- Show characters in defeated poses
- Same size as regular character images
